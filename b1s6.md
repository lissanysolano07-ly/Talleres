### Ejercicio 1: Buscar notas (Option)

Implementa una función `buscarNota` que reciba la cédula de un estudiante y devuelva su nota como un `Option[Double]`. Si el estudiante no existe, devuelve `None`.

Luego, a partir de una lista de cédulas, calcula el promedio de las notas **de los estudiantes que sí existen**.

```scala
println(buscarNota("1101"))   // Some(9.5)
println(buscarNota("9999"))   // None

val cedulas = List("1101", "9999", "1103", "0000")
val notas = ???     // List(Some(9.5), None, Some(8.0), None)
val promedio = ???  // 8.75
```

```scala
case class Estudiante(cedula: String, nombre: String, nota: Double)

val estudiantes = List(
  Estudiante("1101", "Ana", 9.5),
  Estudiante("1102", "Luis", 6.8),
  Estudiante("1103", "Sofía", 8.0)
)

// Buscar la nota de un estudiante por su cédula
def buscarNota(cedula: String): Option[Double] = {
  estudiantes.find(e => e.cedula == cedula).map(e => e.nota)
}

// Pruebas
println(buscarNota("1101"))  // Some(9.5)
println(buscarNota("9999"))  // None

// Lista de cédulas
val cedulas = List("1101", "9999", "1103", "0000")

// Buscar las notas
val notas = cedulas.map(buscarNota)
println(notas)

// Calcular el promedio solo de los que existen
val notasValidas = notas.flatMap(x => x)

val promedio = notasValidas.sum / notasValidas.size

println("Promedio: " + promedio)

```

### Ejercicio 2: Comprar entradas (Either)

Implementa una función `comprarEntrada` que reciba un `Evento`, la edad y el saldo de un usuario, y devuelva un `Either[String, Double]` con el saldo restante.

**Reglas** (en este orden):

1. Si el evento no tiene cupos, devuelve `Left("Evento agotado")`
2. Si la edad es menor a la edad mínima, devuelve `Left("No cumple la edad mínima")`
3. Si el saldo es menor al precio, devuelve `Left("Saldo insuficiente")`
4. En otro caso, devuelve `Right` con el saldo restante

Luego, usando `match`, genera un mensaje por cada evento de la lista para un usuario de **17 años** con **50.0** de saldo.

**Estructura de `map` y `match` con `Either`:**

```scala
lista.map(elemento =>
  funcion(elemento) match {
    case Right(valor) => // qué hacer si la operación fue exitosa
    case Left(error)  => // qué hacer si hubo un error
  }
)
```

**Tu tarea:** Completa el siguiente código. Implementa `comprarEntrada` y obtén la lista `mensajes`, que debe producir la salida indicada.

```scala
case class Evento(nombre: String, precio: Double, edadMinima: Int, cupos: Int)

val eventos = List(
  Evento("Rock en el Parque", 45.0, 18, 100),
  Evento("Festival Pop", 60.0, 14, 0),
  Evento("Noche Urbana", 35.0, 16, 50),
  Evento("Concierto Sinfónico", 70.0, 0, 20)
)
```

```scala
// Función comprarEntrada
def comprarEntrada(evento: Evento, edad: Int, saldo: Double): Either[String, Double] = {
  if (evento.cupos <= 0) {
    Left("Evento agotado")
  } else if (edad < evento.edadMinima) {
    Left("No cumple la edad mínima")
  } else if (saldo < evento.precio) {
    Left("Saldo insuficiente")
  } else {
    Right(saldo - evento.precio)
  }
}

// Pruebas
println(comprarEntrada(eventos(2), 17, 50.0))
println(comprarEntrada(eventos(1), 17, 50.0))

// Generar mensajes
val mensajes = eventos.map(e =>
  comprarEntrada(e, 17, 50.0) match {
    case Right(restante) =>
      s"${e.nombre}: Compra exitosa, saldo restante $restante"
    case Left(error) =>
      s"${e.nombre}: $error"
  }
)

mensajes.foreach(println)

```
